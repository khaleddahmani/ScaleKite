# ScaleKite

ScaleKite is a distributed data processing engine that enables auto-scaling of complex analytics workloads on a scalable platform.

ScaleKite is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/ScaleKite.git`
2. `cd ScaleKite`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
